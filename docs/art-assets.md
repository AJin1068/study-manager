# 캐릭터·옷 그림 자산: 자리표시 SVG 교체 절차 (4단계, O-13)

에이전트는 그림을 그릴 수 없으므로 캐릭터와 옷은 **자리표시 도형(색 도형 SVG 조각)**으로 구현되어 있다. 실제 그림은 사용자가 만들거나 외주를 준다. 교체 지점은 코드가 아니라 데이터 파일 두 개다.

## 교체 지점

| 파일 | 내용 |
|---|---|
| `src-tauri/assets/character/parts.json` | 종(species), 털 색(palettes), 표정(expressions), 소품(props). 각 항목의 `svg`가 도형 조각 템플릿이다. |
| `src-tauri/assets/character/items.json` | 상점 아이템(옷 4슬롯, 오두막 가구, 추가 캐릭터). 옷의 `svg`는 슬롯 앵커 상자 위에 그려지는 템플릿이다. |

두 파일은 `include_str!`로 컴파일 시 포함된다. 렌더링은 `character::render`(순수 함수)가 SVG 문자열을 만들고, UI는 그것을 `<img src="data:image/svg+xml...">`로 보인다. 스크립트가 실행되지 않는 이미지 경로만 쓴다.

## 몸 비율 정렬 (옷을 모든 캐릭터가 공유하는 방식)

- 종마다 `body`(머리 중심 높이·반지름, 몸통 너비·높이)가 있고, 캔버스는 `0 0 100 100`이다.
- 슬롯별 앵커 상자(`character::render::anchor`)가 몸에서 계산된다: 모자 = 머리 꼭대기, 옷 = 몸통 전체, 소품 = 목, 손 = 몸통 옆.
- 옷 `svg`는 `{x} {y} {w} {h} {xr} {yb} {cx} {cy}` 등 앵커 변수로 쓴다. 같은 옷이 모든 종에 맞는다.
- 종 조각(귀, 꼬리 등)은 `{cx} {cy} {r} {top} {left} {right} {lq} {rq} {tt} {tm} {fur} ...` 머리 변수를 쓴다. 변수 전체 목록은 `render.rs`의 `head_vars`, `anchor_vars`.
- 시험(`character::tests`)이 모든 종 x 모든 옷을 렌더해 치환되지 않은 `{...}`가 없음과 앵커가 캔버스 안에 있음을 확인한다. 새 그림을 넣은 뒤에도 이 시험이 통과해야 한다.

## 교체 절차

1. 종·소품·표정은 `parts.json`의 해당 항목 `svg`를 실제 도형 조각으로 바꾼다. id는 바꾸지 않는다(저장된 캐릭터가 id를 참조한다). 새 종은 `shop_only`와 `body`를 함께 적는다.
2. 옷은 `items.json`의 `svg`를 바꾼다. 앵커 상자 크기에 맞춰 그리고 종마다 몸 비율이 달라도 어긋나지 않는지 확인한다.
3. 통짜 이미지(PNG 등)를 쓰려면 `render.rs`의 조립 부분을 이미지 레이어 합성으로 바꾸는 별도 작업이 필요하다. 이 문서의 절차는 SVG 조각 교체까지다.
4. `cd src-tauri && cargo test --lib character:: shop::` 로 형식 시험을 돌린다.
5. 사람이 보고 확인한다(검증 안 됨 V4-3: 시각 품질, 옷 정렬, 선택 화면 사용성).

## 오리지널 원칙

- 기존 영화·만화·게임 캐릭터(지브리 포함)의 이름과 모양을 쓰지 않는다. `character::catalog::is_banned` 금칙어 목록과 시험이 라벨, 내장 이름, 모델이 지은 이름을 걸러낸다. 금칙어 목록은 완전하지 않으므로 외주 시안은 사람이 검토한다.
