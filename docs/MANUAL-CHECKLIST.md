# MANUAL-CHECKLIST — 사람이 직접 눌러봐야 하는 항목

작성: 2026-11-07, Windows PC 검증 이후. 자동으로 확인 가능한 항목은 각 `docs/stage-*-verification.md`의 「Windows PC 검증 결과」 표에 명령·결과를 적었고, 여기에는 **사람만 할 수 있는 것**만 순서대로 모았다. 항목 ID는 해당 문서의 ID(`#N` = `stage-1-5-verification.md` 총괄표, `V2-x`~`V5-x` = 각 단계 문서)이다. 체크하면서 결과를 해당 문서에 반영한다. 이 체크리스트를 다 채우기 전에는 1~5단계 완료로 표기하지 않는다.

## 0. 준비

- [ ] Windows 설치본 만들기: `pnpm tauri build --bundles nsis` (산출물 `src-tauri/target/release/bundle/nsis/Study Manager_0.1.0_x64-setup.exe`, 이 PC에서 빌드됨·설치/실행은 안 해 봄). 기존에 떠 있는 개발용 `study-manager.exe`는 먼저 종료한다(단일 인스턴스 잠금 때문에 스모크가 판정 불가였음).
- [ ] 크롬 확장 빌드: `pnpm build:extension` → `extension/dist`.
- [ ] (5단계) Windows 개발자 모드 켜기(설정 → 개발자용). 안 켜면 `tauri android build`가 심볼릭 링크 권한 오류로 APK 단계에서 멈춘다.
- [ ] (선택, 서버 항목) Docker Desktop(WSL2, 관리자·재부팅 필요) + Supabase CLI. 없으면 SQL은 스텁 PG 결과(`supabase/tests/stub/run.ps1`, 부분 검증)로만 남는다.
- [ ] 준비물: Supabase 프로젝트와 계정 2개(메일 수신 가능), Anthropic API 키, 크롬, 안드로이드 폰(접근성 서비스 허용 가능), 폰의 ntfy 앱, 필요하면 Telegram.
