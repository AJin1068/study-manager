# Study Manager 기획서 (PLAN.md)

> 이 파일이 모든 요구사항의 기준(SSOT)이다. 원본은 Claude Docs 기획서(https://claude.ai/artifact/V4db7vrcC1HHmgz6kqMj4s)이고, 2026-11-05 기준으로 옮겼다. 기획이 바뀌면 이 파일을 먼저 고친다.
> 기능은 번호(1~17)로, 로드맵은 "N단계-M"으로 부른다.

## 개요

Study Manager는 캘린더 계획대로 공부 시간을 자동으로 시작하고, 공부 중에는 딴짓 앱과 사이트를 막고, 쉬는 시간에는 풀어주는 나만의 공부 도우미다.

세 가지로 집중 문제를 해결한다.
- **막기:** 앱 차단, 사이트 차단, 폰 잠금
- **재기:** 집중이 깨지는 순간 측정
- **채우기:** LLM Wiki로 공부 내용과 퀴즈를 연결

핵심 아이디어: 딴짓하려는 순간을 복습 시간으로 바꾼다. 차단된 앱·사이트를 열면 내 위키에서 뽑은 퀴즈가 뜬다.

## 기능 목록

### 1. 시간표와 타이머
- 캘린더 계획(8번)에 따라 공부 모드가 자동으로 시작된다. 예: 20:00 시작, 중간 모드(공부 50분 / 휴식 15분) × 3세트.
- 맥 메뉴바, 윈도우 트레이에 남은 시간이 항상 보인다.
- 휴식이 1분 남으면 "곧 공부 시작" 미리 알림.
- 세트가 끝나면 오늘 공부 시간과 딴짓 시도 횟수를 요약.

### 2. 앱 차단
- 공부 시간에 차단 목록의 앱이 켜지면 종료하고 알림을 띄운다. 정상 종료 요청을 먼저, 응답이 없을 때만 강제 종료.
- 휴식 시간에는 앱 **차단 집행만** 풀린다. 설정·종료·계획 변경 잠금은 휴식 중에도 유지된다(13번, 계획된 공부 run 전체 잠금).
- 중간에 끄려면 귀찮은 절차: 처음엔 긴 문장 타이핑, 위키가 생기면 **조기 해제만** 위키 퀴즈 3문제를 전부 맞혀야 한다(하루 4회 시도, 틀리면 3분 쿨다운). 시도를 다 쓰면 그날은 조기 해제를 쓸 수 없고 타이핑으로 대신하지 않는다. 위키 문제가 3개 미만이면 조기 해제도 타이핑. 오늘 건너뛰기와 긴급 패스는 위키와 무관하게 긴 문장 타이핑과 각자의 일일 한도를 유지한다.
- "오늘 건너뛰기"와 하루 1~2회 긴급 패스. 사용 기록은 통계에 남는다.
- 브라우저 확장 프로그램으로 사이트 차단 (1단계에 포함).

**차단 목록 추천 프리셋** (첫 실행 때 카테고리별로 켜고 끔)

| 카테고리 | 앱 | 사이트 | 기본값 |
| --- | --- | --- | --- |
| 메신저 | 카카오톡, 디스코드, 텔레그램 | 웹 카톡, discord.com | 켜짐 (긴급 패스로 잠깐 허용) |
| 영상 | 넷플릭스, 쿠팡플레이, 티빙 앱 | youtube.com, netflix.com, chzzk.naver.com, twitch.tv | 켜짐 |
| SNS | - | instagram.com, x.com, threads.net, facebook.com | 켜짐 |
| 커뮤니티 | - | 디시인사이드, 에펨코리아, 더쿠, reddit.com | 켜짐 |
| 게임 | 스팀, 라이엇 클라이언트, 배틀넷, 에픽게임즈 | - | 켜짐 |
| 쇼핑·웹툰 | - | 쿠팡, 29CM, 네이버 웹툰 | 꺼짐 |

- 유튜브: 막되, 설정에 등록한 공부 재생목록·채널은 허용. 애매한 영상은 Haiku가 제목으로 판단.
- 엄격 모드: 브라우저에서 공부 사이트(강의 플랫폼, 문서, GitHub, 내 위키)만 허용.
- 음악 앱(멜론, 스포티파이)은 기본 허용.

**브라우저 판단 흐름** (서버로 보내지 않고 내 PC에서 처리)
1. 확장 프로그램은 탭 전환·주소 변경 때만 로컬 Study Manager 앱에 주소와 제목을 넘긴다. 주기적으로 보내지 않는다.
2. 차단·허용 목록은 규칙으로 즉시 판단 (대부분 여기서 끝).
3. 전에 판단한 주소·영상은 캐시 결과 사용.
4. 처음 보는 애매한 것만 Haiku에 묻는다(설정에서 켠 경우에만, 기본 꺼짐). 보내는 건 도메인, 짧게 줄인 탭 제목, 현재 공부 주제뿐이고 경로·쿼리·페이지 내용은 안 보낸다. 결과는 캐시(제목·주소 평문은 저장하지 않음). 첫 판단은 규칙 결과로 즉시 내리고 모델 결과는 다음 이벤트부터 반영한다.
- Supabase에는 "공부 중/딴짓" 상태와 횟수만 올라간다. 탭 기록은 로컬에만.
- 설정에서 LLM 판단을 끄면 목록에 없는 사이트는 허용(보통 모드) 또는 차단(엄격 모드).

### 3. 응원·채찍 메시지
- 일정 간격 랜덤, 또는 딴짓 시도·연속 달성 같은 이벤트 때 보낸다.
- 말투는 다정함~독설 단계로 선택. MBTI(15번)로 기본값 설정.
- 3단계부터 위키 내용 활용. 예: "어제 정리한 TCP 3-way handshake, 3단계 다 말할 수 있어?"

### 4. 집중 측정

| 신호 | 알 수 있는 것 | 비고 |
| --- | --- | --- |
| 맨 앞 앱 | 공부 앱이 앞에 있는지 | 권한 불필요 |
| 창 제목 | 같은 크롬이어도 공부인지, 무엇을 보는지 | 맥은 화면 기록 또는 접근성 권한 필요 |
| 브라우저 탭 주소 | 가장 정확 | 확장 프로그램 |
| 키보드·마우스 입력 | 실제로 하는지 | 10분 입력 없으면 멍때림 의심 |
| 폰 사용 | 폰을 안 만졌는지 | 5단계 |

- 이탈은 "공부 앱 → 비공부 앱" 전환만 센다 (문서↔에디터 왕복은 정상).
- 판단은 목록 규칙 우선, 애매한 창 제목은 LLM 분류.
- 무엇을 공부했는지: 계획 주제 + 파일명·창 제목 + 세션 회고를 합쳐 위키 페이지와 연결. 예: "오늘 운영체제 3강 40분".
- 직접 알려주는 신호: 랜덤 체크인("지금 집중하고 있었어?"), "방금 딴생각함" 단축키, 세션 끝 위키 퀴즈 정답률.
- 지표: 첫 이탈까지 시간, 딴짓 후 복귀 시간, 세션별 집중 점수·타임라인, 요일·시간대 히트맵.
- 카메라는 쓰지 않는다. 아날로그 공부는 측정하지 않는다.
- 창 제목·탭 기록은 로컬에만 저장하고 친구에게는 상태만 보낸다.

### 5. LLM Wiki 연동
위키는 저장소이면서 교재다. 넣기 → 불러와서 공부 → 다시 저장이 계속 돈다.
1. 넣기: PDF, 필기, 링크를 넣으면 LLM이 주제별 위키 페이지로 정리.
2. 불러와서 공부: 공부 시간에 오늘 주제 페이지를 띄우고 퀴즈도 거기서 뽑는다.
3. 다시 저장: 세션 회고를 해당 페이지에 합치고 보강.

- 딴짓 = 퀴즈 관문: 차단된 앱을 켜면 위키 문제 하나. 복습·보너스일 뿐 차단은 풀리지 않는다(답과 무관하게 차단 판단 불변).
- 조기 해제 = 위키 문제 3개(전부 정답). 이 규칙은 조기 해제에만 적용되며 건너뛰기·긴급 패스는 타이핑을 유지한다. 시도 소진 후 조기 해제는 그날 불가(타이핑 비개방).
- 세션 회고("뭐 배웠어?")를 위키에 합치고 개념끼리 연결.
- 위키가 다음 주제를 정함: 비었거나 자주 틀린 페이지를 다음 공부 시간에 배정.
- 집중 데이터와 결합: 집중 잘 되는 시간대엔 어려운 주제, 안 되는 시간대엔 복습·퀴즈.
- 위키가 비어 있는 초기엔 퀴즈 대신 긴 문장 타이핑.

**과목 동적 추가**
- 위키는 과목별 폴더. 과목은 언제든 추가·보관.
- 캘린더에 계획을 만들 때 새 과목 이름을 적으면 그 자리에서 과목 생성.
- 과목에 PDF·필기·링크를 끌어다 놓으면 LLM이 첫 페이지 생성. 자료가 없으면 과목 이름으로 목차 초안 제안.

### 6. 친구 연동 (스터디방)
- 여러 명이 쓰는 스터디방. 방을 만들면 초대 코드·QR, 친구가 그걸로 입장.
- 모두의 상태 실시간 표시. 예: "아진: 공부 중, 32분 남음 / 민수: 휴식 중".
- 딴짓 시도 알림(사람마다 켜고 끔, 기본 꺼짐), 오늘·이번 주 공부 시간 랭킹, "같이 공부 모드"(같은 시간표).
- 화면 공유는 디스코드에 맡기고 앱은 상태만 공유.

**공유 위키**
- 내 위키 페이지 중 공유할 것만 방에 올림. 개인 메모는 비공개.
- LLM이 여러 사람의 페이지를 하나의 공유 페이지로 합치고 기여자 표시.
- 친구가 정리한 개념이 내 위키에 없으면 알림. 공유 위키로 서로 퀴즈, 하루 요약.
- 저장: Supabase Storage 또는 스터디방별 GitHub 저장소.

### 7. 폰 잠금
- 공부 시간에 전화와 허용 앱을 빼고 전부 차단 화면으로 덮는다 (완전한 먹통은 OS가 허용하지 않음).
- 안드로이드: 접근성 서비스(Kotlin). 아이폰: Screen Time API(Swift, 애플 권한 승인 필요). Tauri 플러그인으로 붙인다.
- 설치: PC 앱이 QR을 보여주고 폰으로 찍으면 APK 다운로드 (같은 와이파이에서 PC가 전달, 또는 GitHub Releases 링크).
- 짝짓기: 설치 후 QR을 한 번 더 찍으면 PC와 폰 연결. 이후 공부·휴식 신호가 폰으로.
- 공부 중 폰을 집어 든 횟수를 집중 측정 데이터로 보냄.
- 코드 없는 임시 방법: 아이폰 스크린 타임 다운타임 / 안드로이드 디지털 웰빙 집중 모드.

### 8. 캘린더 공부 계획
- 날짜·시간별 공부 계획. 예: 11월 12일 20:00~22:00 운영체제 3강. 반복 일정 가능.
- 이 캘린더가 자동 시작의 기준.
- 2단계: .ics 파일 가져오기(미리보기 후 적용)·내보내기(설정 「캘린더 가져오기·내보내기」, 기본 꺼짐). 로컬 파일만 쓰고 네트워크는 없다.
- 나중에: 구글·애플 캘린더 API 직접 연동.

### 9. PC를 안 켜면 폰 알림
- 계획 시간이 지났는데 PC 앱이 켜져 있지 않으면 폰으로 알림. 예: "20:05인데 아직 안 앉았어!"
- PC 앱이 1분마다 "켜져 있음" 신호를 서버에 보내고, 서버가 계획 시간에 신호가 없으면 알림.
- 폰 앱 전에는 텔레그램 봇이나 ntfy로 받는다.
- 유예는 기본 3분(설정 1~3분, 4 이상 거부), 서버 감지는 1분 주기라 최악 약 4분 10초에 도착한다.
- 알림 문구에는 과목·계획 이름을 넣지 않는다(잠금 화면 노출). 시각과 「신호가 없어요」만 쓴다.
- 건너뛴 날·취소·이동된 계획, 시작 이후 신호가 있었던 계획, 시작 30분이 지난 계획은 알리지 않는다. PC가 켜져 있는데 네트워크만 끊긴 경우는 오탐이 날 수 있다.

### 10. 계획 수정 히스토리
- 옮기기·삭제·시간 변경을 모두 기록. 덮어쓰지 않고 이력을 쌓는다(append-only).
- 기록: 언제, 무엇이, 전→후, 이유("밀림", "아픔", 직접 입력).
- 계획별 타임라인, "이번 달 밀린 횟수", "가장 자주 밀리는 과목" 통계.
- 설정 변경도 히스토리에 남는다.

### 11. 대시보드
네 가지 질문에 위에서부터 답한다. 처음 열면 "오늘"만 봐도 충분하게.

| 영역 | 질문 | 내용 | 단계 |
| --- | --- | --- | --- |
| 오늘 | 지금 뭐 해야 해? | 다음 계획까지 남은 시간, 오늘 계획 대비 실제, 연속 달성일, 내 캐릭터와 레벨 | 1단계 |
| 이번 주 | 잘하고 있나? | 요일별 계획 대비 실제, 달성률, 집중 점수 추세, 과목별 시간 | 1단계 |
| 약점 | 어디서 무너지나? | 딴짓 앱 순위, 첫 이탈까지 평균, 요일·시간대 히트맵, 자주 밀리는 계획 | 1~2단계 |
| 성장 | 얼마나 컸나? | 누적 시간, 레벨 진행도, 위키 페이지 수, 퀴즈 정답률, 다음 복습 주제 | 3단계 |

- 주간 한 줄 인사이트: LLM이 데이터를 읽고 행동을 하나 제안. 예: "토요일 오후 계획이 3번 중 2번 밀렸어요. 줄여볼까요?"
- PC 앱 안에서 보고, 스터디방이 생기면 웹에서도. 친구에게는 레벨·캐릭터·주간 공부 시간만.

### 12. 포인트, 레벨, 캐릭터
- 딴짓 없이 30분 공부 달성 시 포인트(+20P 예시). 계획대로 시작·퀴즈 정답 보너스. 긴급 패스 사용 시 차감.
- 포인트가 쌓이면 레벨업. 레벨은 친구에게 보임.
- 포인트로 캐릭터 변경·꾸미기. 캐릭터는 메뉴바, 대시보드, 스터디방에 나타남.
- 농땡이 방지: 공부 앱이 앞에 있고 입력이 있는 시간만 인정.
- 그림 방향: 손그림 수채화 느낌의 따뜻한 자연 판타지(지브리 같은 분위기). **캐릭터는 전부 오리지널**, 기존 작품 캐릭터나 "지브리" 이름은 앱·홍보에 쓰지 않는다.
  - 예시: 책 읽는 숲지기 너구리, 이끼 정령, 램프 든 부엉이, 찻잎 고양이.
  - 레벨에 따라 성장: 씨앗 → 새싹 → 작은 나무 → 숲의 정령.
  - 포인트로 "공부 오두막" 배경(책장, 창밖 풍경, 촛불, 화분) 꾸미기.
  - 그림 제작: 일러스트레이터 외주, 직접 그리기, 상업 이용 허용 AI 이미지 도구로 오리지널 생성.

**옷 입히기**
- 캐릭터 위에 옷을 겹쳐 그림. 슬롯 4개: 모자, 상의, 목도리·액세서리, 손 소품.
- 포인트로 사거나 업적으로 획득. 예: 7일 연속 → 뜨개 목도리, 퀴즈 100문제 정답 → 작은 학사모.
- 친구에게 입은 모습 그대로 보임.
- 캐릭터들의 몸 비율과 옷 위치를 맞춰 옷 하나를 여러 캐릭터가 공유.

### 13. 자동 실행과 설정 페이지
- 기본값: 로그인 시 자동 실행(맥 로그인 항목, 윈도우 시작 프로그램, Tauri autostart).
- 수면: 잠들면 감시와 "켜져 있음" 신호 중지, 깨어나면 즉시 재시작하고 현재 계획 확인.
  - 깨우기 신호(DidWake)가 빠지면, 잠들기 신호(WillSleep)부터 추정 꺼진 시간으로 기록한다. 추정은 잠들기 신호 시각에서 시작해 90초 이상 지나 처음 실행된 점검 시각에서 끝나고, 그 자리에서 잠들기 상태를 닫는다. 점검은 깨어 있을 때만 돌기 때문에 점검이 돌았다는 사실이 깨어났음을 보여준다. 추정 오차는 실제 수면이 90초 이상이면 하트비트 간격(30초) 이내다. 더 짧은 수면은 최대 약 120초(임계 90초 + 하트비트 30초)까지 과대 추정될 수 있다. 추정 뒤 깨어 있는 점검은 행을 더 만들지 않는다. 깨우기 신호가 추정 뒤에 도착하면 기록하지 않고 로그(`did_wake_after_estimate`)로 남긴다.
- 계획 시간에 강제 종료되면 다시 실행, 꺼진 시간은 통계에 표시.
- 우회 방지: **계획된 공부 run(공부 + 사이 휴식 전체) 동안 모든 설정이 잠긴다**(공부 모드 포함, 딴짓 여지를 최대한 없애기 위해). run 밖에서만 바꿀 수 있고, 모든 변경과 거절된 시도는 히스토리에 남는다.

| 분류 | 설정 | 기본값 |
| --- | --- | --- |
| 일반 | 로그인 시 자동 실행 | 켜짐 |
| 일반 | 수면에서 깨면 계획 다시 확인 | 켜짐 |
| 일반 | 강제 종료 허용 (체크하면 기록, 실제 집행은 1단계-3) | 꺼짐 |
| 계획 | 공부 모드와 모드별 공부·휴식 길이 | 중간 (50분 / 15분) |
| 계획 | 캘린더 가져오기·내보내기 | 꺼짐 |
| 차단 | 차단할 앱·사이트 목록, 공부 앱 목록 | 추천 프리셋 |
| 차단 | 하루 긴급 패스 횟수, 해제 방식 | 1회, 긴 문장 타이핑 |
| 알림 | 응원·채찍 말투와 빈도 | 보통 (MBTI로 조정) |
| 알림 | 폰 알림 채널 (텔레그램, ntfy, 폰 앱) | 없음 |
| 친구 | 친구에게 보여줄 정보, 딴짓 알림 공개 | 레벨·상태만, 끔 |
| LLM | Anthropic API 키, 모델, 위키 폴더 위치, LLM 켜기, LLM 판단 켜기 | Haiku, ~/StudyWiki, 둘 다 꺼짐(키와 동의 전 전송 0) |

### 14. 계획 챗봇
Haiku가 캘린더, 집중 통계, 위키 과목을 읽고 계획 도구(tool use)로 계획을 만들고 고친다.
- 새 계획: "다음 주 토요일 정처기 필기 시험이야. 평일 저녁만 돼." → 빈 시간 확인 후 과목을 나눠 제안. 부족한 정보는 한두 개만 되묻기.
- 계획 수정: "오늘 못 했어, 내일로 밀어줘" → 옮기고 히스토리에 "밀림". 뒤 계획 겹침 조정.
- 데이터 활용: 집중 잘 되는 시간대엔 어려운 주제, 자주 밀리는 요일엔 가벼운 복습, 위키 약한 페이지는 복습 배치.
- 미리보기 후 적용: 캘린더에 초안을 흐릿하게 보여주고 "적용"을 눌러야 저장. 히스토리에 "챗봇이 만듦".
- 공부 run 중 "계획 취소" 같은 요청은 설정 잠금(13번)과 같은 규칙을 따른다.
- 위치: 캘린더 옆 채팅 창, 메뉴바 아이콘 입력창.

### 15. 캐릭터 초기 설정
첫 실행 때 MBTI, 태어난 해, 성별을 입력하면 캐릭터 후보 3~4개를 보여주고 하나를 고른다.
- 생성 방식: 미리 그린 부품(동물 종류, 털 색, 표정, 소품)을 규칙으로 조합. 그림체 일관, 옷 슬롯 호환, 비용 없음.
- MBTI: 성격·분위기 결정(I 조용한 숲 동물, E 활발한 동물, T 도구 든 모습, F 꽃·차 든 모습). 응원 말투 기본값에도 반영.
- 태어난 해: 띠 동물을 후보 중 하나로.
- 성별: 기본 옷 후보에만 사용, "선택 안 함" 가능. 세 항목 모두 건너뛸 수 있음.
- Haiku: 고른 캐릭터의 이름 후보와 한 줄 소개. 예: "조용한 밤에 램프를 켜는 부엉이, 모래."
- "다시 뽑기" 가능. 입력 정보는 로컬에만 저장, 친구에게 안 보임.
- 고도화: 이미지 생성 API로 완전히 새 캐릭터 (Claude는 이미지를 만들지 못하므로 별도 서비스).

### 16. 프로필 홈과 선물
친구가 들어와 볼 수 있는 나만의 공부 홈. 앱 안과 웹 링크에서 열린다.
- 내 방: 꾸민 공부 오두막 안의 캐릭터(입은 옷·가구 그대로).
- 공부 잔디: GitHub처럼 일 년 치 날짜별 공부 시간.
- 레벨과 업적 배지(30일 연속, 새벽 공부왕, 퀴즈 마스터 등).
- 방명록(응원 한마디), 오늘·전체 방문자 수.
- 공개한 위키 페이지와 지금 공부 중인 과목.
- 공개 범위: 전체 / 친구만 / 비공개, 칸마다 숨기기. 딴짓 통계는 항상 비공개.

**옷 선물**
- 내 포인트로 옷·가구를 사서 한마디와 함께 친구에게 보냄. 선물 상자 알림.
- 포인트 자체는 주고받을 수 없음(부계정 악용 방지). 아이템만.
- 업적 전용 아이템은 선물 불가.
- 받은 선물은 프로필에 "민수가 준 목도리"처럼 표시 가능.

### 17. 공부 모드 (쉬움·중간·어려움)와 계획 자동 조정
- 공부 모드는 공부·휴식 시간 길이를 정한다. 사용자가 날마다 수동으로 고른다. 기본값(설정에서 변경 가능):

| 모드 | 공부 / 휴식 | 근거 |
| --- | --- | --- |
| 쉬움 | 25분 / 5분, 4세트마다 긴 휴식 20분 | 뽀모도로 기법. 집중이 쉽게 깨지는 사람도 버티는 짧은 블록 |
| 중간 | 50분 / 15분 | 생산성 상위 사용자의 평균 패턴(약 52분 일 / 17분 휴식, DeskTime 조사)을 반올림 |
| 어려움 | 90분 / 10분 | 약 90분 주기의 집중 리듬과 숙련자 연습 세션 길이(최대 60~90분)를 상한으로 사용 |
- 모드를 바꾸면 길이가 달라져 뒤의 계획이 앞당겨지거나 밀린다. 남은 계획 재배치는 LLM(Haiku)이 판단해 자동으로 수정한다.
  - 입력: 남은 계획, 모드별 길이, 고정 일정(마감·약속), 하루 종료 시각. 출력: 수정된 계획(JSON), 이유 한 줄.
  - 자동 적용하되, 변경 내용을 알림으로 보여주고 한 번에 되돌리기 가능. 모든 수정은 10번 히스토리에 "LLM 자동 조정"으로 남긴다.
  - LLM을 쓸 수 없으면(키 없음, 오프라인) 규칙 기반으로 뒤 계획을 차이만큼 일괄 이동.
- 우회 방지: 계획된 공부 run(공부 + 사이 휴식 전체) 동안 모드를 포함한 모든 설정이 잠긴다(13번 전체 잠금). 모드는 run 밖에서만 바꾼다.
- 단계: 모드와 길이 설정은 1단계-1(설정)·1단계-2(타이머), 규칙 기반 이동은 1단계-2, LLM 자동 조정은 3단계(14번 챗봇과 같은 Haiku 호출 계층).

## 시스템 구조와 기술 스택

- **PC 앱 (Tauri, 맥·윈도우):** 공통 코어(Rust: 시간표·타이머, 차단 목록, 집중 기록, 메시지) + OS별 층(맥/윈도우: 앱 목록, 앱 종료, 알림).
- **폰 앱 (Tauri 모바일):** 공통 화면(타이머, 시간표 수신, 폰 집어 든 횟수) + 차단 플러그인(안드로이드 Kotlin 먼저, 아이폰 Swift 나중).
- **LLM Wiki (마크다운 폴더):** 퀴즈 만들기, 회고 합치기, 다음 공부 주제 추천. PC 앱과 회고·퀴즈를 주고받음. 파일이 진실이고 SQLite는 다시 만들 수 있는 색인이며, LLM이 꺼져 있어도 로컬 정리·검색은 동작한다.
- **Supabase (서버):** 스터디방, 실시간 상태, PC-폰 짝짓기, 계획·히스토리 읽기용 미러, 친구 앱 연결, 놓친 계획 감지(pg_cron 1분 + Edge Function).
- **외부 연동 구조 (2단계~):** 외부 서비스는 포트/어댑터로 붙인다(Supabase, 알림, LLM, 푸시). 설정이 없으면 「설정 필요」, 명시하면 키 없이 도는 「모의 모드」(외부로 아무것도 안 나감). 나가는 요청은 허용 목록 타입만 만들 수 있고 호스트는 주입된 정책이 제한한다(docs/egress-policy.md). 비밀(로그인 토큰, API 키, ntfy 토픽)은 OS 키체인에만 둔다.
- PC 앱 ↔ 폰 앱: QR로 연결. PC 앱 ↔ Supabase: 상태 동기화. 폰 앱 ↔ Supabase: 공부·휴식 신호.

| 영역 | 기술 | 비고 |
| --- | --- | --- |
| 앱 틀 | Tauri 2 | 데스크톱과 모바일을 하나의 코드로 |
| 핵심 로직 | Rust | 시간표, 차단 판단, 집중 기록 |
| 화면 | React + TypeScript | 타이머, 설정, 통계 화면 |
| 앱 목록·종료 | `sysinfo` 크레이트 + OS별 코드 | 맥: 맨 앞 앱, 윈도우: 활성 창 |
| 알림 | Tauri 알림 플러그인 | 공통 |
| 로컬 저장 | SQLite | 세션 기록, 집중 데이터, 히스토리 |
| 설정 | 설정 파일 (TOML) 또는 SQLite | 시간표, 차단 목록, 말투 |
| 서버 | Supabase (Postgres·RLS, Edge Function, pg_cron) | 읽기용 미러, 켜짐 신호, 놓친 계획 알림, 로그인, 스터디방 |
| 비밀 저장 | OS 키체인 (`keyring`) | 불가하면 세션 한정 + 화면에 표시. DB·로그·이력에는 값도 해시도 없음 |
| 폰 차단 | 안드로이드 접근성 서비스(Kotlin), 아이폰 Screen Time API(Swift) | Tauri 플러그인 |
| 브라우저 | 크롬 확장 프로그램 | 로컬 앱과 통신 (native messaging 또는 localhost, 검증 필요) |
| LLM Wiki | 마크다운 폴더 + Anthropic API (Haiku) | 위키 생성, 퀴즈, 회고 합치기, 분류, 챗봇 |

## 로드맵 (5단계)

단계마다 직접 써보고 다음 단계로 넘어간다. 각 단계 끝의 "완료 기준"을 만족해야 완료다.

### 1단계: PC 차단기 MVP (맥 + 윈도우)
- 캘린더 계획대로 공부·휴식 자동 전환, 계획 수정 히스토리 (로컬 저장)
- 차단 목록 앱 종료(정상 종료 먼저), 알림, 메뉴바·트레이 타이머
- 오늘 건너뛰기, 긴급 패스, 해제 시 긴 문장 타이핑
- 집중 측정(딴짓 시도, 앱 전환, 멍때림), 간단한 대시보드, 포인트와 레벨
- 브라우저 사이트 차단 (확장 프로그램)
- 완료 기준: 맥북에서 일주일 동안 실제로 쓰고 대시보드에 기록이 나옴

**1단계 작업 단위** (단위마다 deep-interview → ralplan → 승인 → ultragoal 한 번씩)
- 1단계-1. Tauri 뼈대: 메뉴바·트레이 아이콘, 자동 실행, 수면·깨어남 감지, 설정 페이지와 저장 (13번)
- 1단계-2. 캘린더 계획과 수정 히스토리, 공부·휴식 타이머, 비상 해제(최소 경로: 긴 문장 타이핑으로 현재 run 중단) (1, 8, 10번)
- 1단계-3. 앱 차단 코어 (맥·윈도우), 오늘 건너뛰기·긴급 패스, 해제 절차 (2번, ralplan `--deliberate`)
- 1단계-4. 브라우저 확장 프로그램과 앱 연결, 차단 프리셋 (2번)
- 1단계-5. 집중 측정, 대시보드, 포인트·레벨 (4, 11, 12번)

### 2단계: 서버 연결과 놓친 계획 알림
- Supabase 로그인, 계획·히스토리 동기화, PC "켜져 있음" 신호 (9, 10번)
- 계획 시간에 PC가 꺼져 있으면 텔레그램이나 ntfy로 폰 알림
- 완료 기준: PC를 안 켜면 5분 안에 폰으로 알림이 옴

### 3단계: LLM Wiki 연동
- 딴짓 시도 때 복습 퀴즈(차단은 유지), 조기 해제 시 위키 문제 3개 (5번)
- 세션 회고를 위키에 합치기, 위키 기반 메시지(3번), 대시보드 통계 확장, 계획 챗봇(14번), 공부 모드 LLM 자동 조정(17번)
- 완료 기준: 한 과목의 위키가 실제 공부로 자라나고 퀴즈가 나옴

### 4단계: 스터디방 (친구 여러 명)
- 초대 코드·QR, 실시간 상태, 레벨과 캐릭터 공개, 랭킹, 공유 위키, 캐릭터 상점, 프로필 홈, 옷 선물 (6, 12, 16번)
- 완료 기준: 친구 2명 이상이 같은 방에서 공부함

### 5단계: 폰 앱
- 안드로이드 APK 먼저: QR로 다운로드, PC와 짝짓기, 차단 화면, 앱 푸시 알림 (7번)
- 아이폰은 애플 Screen Time 권한 승인 후 추가
- 완료 기준: 공부 시간에 폰이 PC와 함께 잠김

## 설계 보완 사항 (구현 시 반드시 반영)

| 문제 | 보완 방법 |
| --- | --- |
| 자동 시작의 예외 상황 (아픈 날, 외출, 급한 업무) | "오늘 건너뛰기"와 하루 1~2회 긴급 패스. 사용 기록은 통계에 남김 |
| 강제 종료로 작업 손실 | 정상 종료 요청을 먼저 보내고, 휴식 종료 1분 전 경고 |
| 브라우저로 우회 | 브라우저 확장 프로그램을 1단계에 포함 |
| 앱 전환 측정의 오해 | 공부 앱 → 비공부 앱 전환만 이탈로 셈 |
| 위키가 비어 있는 초기 | 위키가 없으면 긴 문장 타이핑으로 대체, 자료 한 번에 가져오기 제공 |
| 계획 기준이 여러 개 | 쓰기는 PC 한 곳. 로컬 SQLite가 진실이고 Supabase는 읽기용 미러(폰·방·서버 알림용). 서버가 낡거나 죽어도 PC의 타이머·차단·계획은 그대로 동작 |
| 앱이 꺼지면 감시 중단 | 로그인 시 자동 실행, 꺼지면 다시 켜지기, 꺼진 시간을 통계에 표시 |
| 친구 알림의 부담 | 사람마다 켜고 끌 수 있게, 기본값은 끔 |
| 앱에서 쓸 LLM 키 | gjc의 Haiku 설정과 별개. 앱 설정에 Anthropic API 키를 넣고 앱이 직접 호출 |

## 리스크
- 스스로 끄기 쉬움: 귀찮은 해제 절차와 "앱이 꺼진 기록"을 집중 통계에 남겨 보완.
- 맥 권한: 다른 앱 창 제목을 읽으려면 화면 기록 또는 접근성 권한 필요. 첫 실행 때 안내 화면.
- 아이폰 승인: Screen Time API는 애플 권한 승인이 필요하고 거절될 수 있음. 안드로이드 먼저.
- Tauri 모바일 성숙도: 막히면 폰 앱만 따로 만드는 것도 검토.
- 사생활: 창 제목과 탭 기록은 로컬에만. 친구에게는 상태와 공유하기로 한 위키만.
